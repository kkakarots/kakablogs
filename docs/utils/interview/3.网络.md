### 1.HTTP缓存

`关键字: 强缓存、协商缓存、Cache-Control、ETag`

强缓存用 Cache-Control 和 Expires, Cache-Control 优先级更高

协商缓存用 ETag 和 Last-Modified, ETag 更精确

no-cache 不是不缓存, 是要验证后再用, no-store 才是真不缓存

多节点部署下 ETag 可能不一致, 解决方案是基于内容 hash 或关闭 ETag

304 不传 body, 带宽几乎不消耗

### ajax，axios（fetch）取消请求

`关键词：signal, AbortController`

AbortController（浏览器统一取消请求策略）

```js
const controller = new AbortController()

axios.get('/api/data', {
  signal: controller.signal
})

// 取消请求
controller.abort()
```
